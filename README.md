# SHANNI JIN

A responsive visual prototype based on the supplied personal website brief. Next.js, TypeScript, and plain CSS. Sample writing and locally stored placeholder photography; no backend, CMS, or live Wall submissions.

## Develop

```sh
npm ci --cache /tmp/ni-npm-cache
npm run dev
```

## Verify

```sh
npm run typecheck
npm run build
npm start
```

Pages: Home, Field Notes (Board / Notebook), one Field Note, Images, static Wall, and About. Practice links to Things I Notice on the homepage. Notebook entries link to the representative article or its related passages.

Photography sources are recorded in `public/photos/CREDITS.md`. Replace these and sample copy with personal content before launch. About contact details are intentionally pending rather than invented.
